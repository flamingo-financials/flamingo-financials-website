# Flamingo Financials Public Website

A public-facing residential mortgage servicing website built with HTML5, CSS3, and vanilla JavaScript.

## Pages

- `index.html` — public homepage
- `about.html` — company overview
- `services.html` — homeowner and portfolio servicing capabilities
- `contact.html` — contact information and inquiry form

## Before publication

1. Replace the placeholder contact information in `js/script.js`.
2. Connect the contact form to an approved secure backend or CRM endpoint.
3. Add the company’s official NMLS identifier and licensing disclosures if legally required.
4. Have Legal and Compliance review all servicing, licensing, portfolio, and consumer-facing statements.
5. Confirm the published values for loans serviced and unpaid principal balance.
